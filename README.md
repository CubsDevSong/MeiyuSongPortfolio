# Meiyu Song Portfolio

One-page UX/Product/HCI portfolio built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Main Edit Points

- Portfolio copy and structured data: `src/content/portfolio.ts`
- Content types: `src/content/types.ts`
- Page composition: `src/components/portfolio/portfolio-page.tsx`
- Theme tokens: `src/app/globals.css`

The first version uses local typed content. Supabase is not configured yet.

## Checks

```bash
npm run lint
npm run build
```

## Deployment

The project is ready for a private GitHub repo connected to Vercel. No Git remote is configured yet.
